# Передача ML-разработчику

Веб-часть Worksight готова к интеграции. Контракт пока предложенный: `api-contract.md` и `openapi.proposed.json` рядом с этим файлом. Подтверди его или верни правки. Пока UI использует отдельный, явно помеченный demo-адаптер.

## Минимальный API для первого подключения

- GET `/v1/capabilities`: версия API, лимиты файлов и флаги функций.
- GET/POST `/v1/profiles`: список и создание `{name, description}`.
- POST `/v1/profiles/{id}/samples`: multipart, повторяемое поле `files`, вернуть обновлённый профиль.
- POST `/v1/profiles/{id}/build`: вернуть `{job_id}`.
- GET `/v1/jobs/{id}`: queued/running/succeeded/failed/cancelled, stage, progress 0–1 или null, result и error.
- POST `/v1/inspections`: multipart `profile_id` и `image`, вернуть `{job_id}`.
- GET `/v1/inspections/{id}`: оригинал, прозрачная PNG heatmap в тех же координатах, похожий эталон, model_decision, profile_version, processing_ms или null.
- POST `/v1/inspections/{id}/feedback`: `{human_decision, comment}`, вернуть инспекцию с отдельным feedback. Решение модели не менять.

Решения: pass/fail/review. Успешная задача возвращает profile_id или inspection_id. Недоступные версии/сравнение/откат объявляются false в capabilities.

## Нужен ответ по пяти пунктам

1. Подходит ли этот контракт? Если уже есть API, пришли OpenAPI и адрес.
2. Что именно build использует после исправления инженера? Действительно ли поддерживается обновление? Нельзя автоматически добавлять брак как исправный образец.
3. Какие функции уже работают: feedback, profile_updates, version_history, version_comparison, rollback?
4. Дай доступный адрес FastAPI и способ получить изображения. Ключ установим на сервере через secrets; не отправляй его в общий чат или Git.
5. Для итогового демо нужны реальные исправные образцы, тестовый снимок и подтверждение AMD-пути: фактический GPU, модель, ROCm, команда запуска и результат. Метрики и время покажем только измеренные.

Сохраняемые профили, изображения и результаты принадлежат backend. Веб-часть не заводит второй базы. После получения URL и подтверждения схемы можно проверить реальное создание профиля, инспекцию, сохранение правки и новую версию.
